# Сверка с FBA 1.4 RC3 Hotfix1

Проверено 27 октября 2026 года на установленном моде:

`~/.local/share/PrismLauncher/instances/26.3(1)/minecraft/mods/FBA-1.4-RC3-Hotfix1-MC26.3.jar`

SHA-256: `d069bf0660546fdb03ba1c6bcfe8ea5fa49c1c308a5b204fea66d7559a122d80`.
Файл побайтно совпал с ранее предоставленной копией из «Загрузки».

## Что было реализовано первоначально

Первая браузерная версия была самостоятельным интерпретатором JSON по
пресетам и документации из JAR. Полного переноса игрового движка не было.
На этом этапе говорить о полном совпадении с модом было преждевременно.

## Что проверено по коду и исполнению

С помощью Vineflower 1.11.0 изучены классы самого JAR:

- `AnimationEngine`, `AnimationVisualProgress`, `AnimationPose`;
- `ModularAnimationRegistry` и его Parser/Context/Definition;
- `CompiledAnimation`, `KeyframeTrack`, `KeyframeDefinition`;
- `AnimationBindings`, `AnimationRuntimeAdapter`, `AnimationPivotSupport`;
- `AnimationMaterials`, `OverlayDefinition`, классы Gecko-эффектов;
- `nativebackend.NativeRuntime`, `NativeTransforms`.

Исходники декомпиляции оставлены во временной рабочей папке, в сайт не включены.
Оригинальные вычислительные классы Parser и KeyframeDefinition запущены
на JVM отдельно, без Minecraft, загрузки мира или изменения настроек мода.
Их результаты сохранены в [runtime-reference.json](../tests/fixtures/mod/runtime-reference.json).

Проверка браузерного кода сравнивает **16 выражений** и **34 анимации в 10 точках
времени** с этими результатами. Набор включает все 25 поддерживаемых easing,
шесть порядков вращения, degrees/radians, векторные и компонентные треки,
step, нестандартный pivot, opacity и длительность. Для девяти анимаций
дополнительно сверяются восемь углов блока после преобразования матрицей JOML.
Допуск для поз и координат — 0,000003; математические выражения — 0,000000000001.

## Исправления после сверки

| Область | Поведение браузера после исправления |
| --- | --- |
| Legacy opacity | Число или формула в `material.opacity`, clamp 0…1; ошибочная формула/нечисловой результат дают непрозрачность 1, как в RC3. |
| Арифметика | `-2^2` даёт 4; степень правоассоциативна; `lerp(t,a,b)`, clamp с обратными границами и неизвестные переменные повторяют Parser мода. Неизвестные функции отклоняются. |
| Боковой вектор | При почти вертикальном направлении fallback `sideX=1`, `sideZ=0`. |
| Keyframes | Время и значения округляются в float32; easing берётся с начального ключа, интерполяция и предел float соответствуют KeyframeTrack. |
| Format 3 | Статические transform — числовые массивы; pivot — `group_center` или три числа; статическая opacity в диапазоне 0…1. |
| Duration | `preset` принимает положительную целую длительность до 2147483647 мс, вместо прежнего ограничения десятью минутами. Скорость 1×. Для `settings` сайт использует собственное значение по умолчанию 1000 мс. |
| Legacy rotation | Теперь матрица применяется к координатам блока 0…1, как NativeRuntime; прежнее лишнее вращение вокруг центра удалено. |
| Material layers | Проверяется настоящее поле `material.layers`; неподдерживаемый формат 3 с дополнительными слоями показывает ошибку совместимости вместо неполного превью. |

Legacy-матрица проверена отдельно на комбинированном масштабе, pivot и
повороте; это проверка по разобранной цепочке `CompiledAnimation.offset` →
`NativeRuntime`, а не запуск всего игрового пути legacy с Minecraft-контекстом.

## Границы совместимости

| Возможность | Состояние |
| --- | --- |
| Основные transform форматов 1/2, обычные порядки вращения и opacity | Реализованы для эталонного единичного блока. |
| Основные transform/opacity-треки формата 3 | Реализованы, есть сравнение с оригинальными вычислительными классами. |
| Внешний вид мира | Куб с процедурными текстурами; игровые модели, resource packs, освещение мира, shaderpacks и поведение составных блоков не перенесены. `group_center` для куба равен `[.5,.5,.5]`. |
| PNG/glint, UV и coverage дополнительных `material.layers` | Не реализованы. |
| Secondary animations, Gecko-слои и глобальные игровые настройки variation/time mapping | Не реализованы; дополнительные слои формата 3 отклоняются. Внешние Gecko-настройки legacy-пресета из JSON восстановить нельзя. |
| FPS/время | Браузер использует непрерывное время и лимит отрисовки 30 fps; игровая квантизация AnimationVisualProgress и настройки Minecraft не воспроизводятся. |
| Парсер | Без eval; есть ограничения размера/вложенности и диапазона видимого transform. Это интерпретатор поддерживаемого подмножества, не полная копия валидатора мода. Редкие legacy rotation_order с повторяющимися осями не поддерживаются. |

Совпадение выбранных вычислений не означает идентичность всего игрового
рендера или совместимость со всеми возможными будущими пресетами.

## Повторение проверки

Обычный `npm test` использует сохранённый эталон и не требует Java или мода.
Для регенерации нужен исходный JAR, Gson, JOML и JDK 25+:

```bash
node tests/reference/generate.mjs /path/FBA.jar /path/gson.jar /path/joml.jar /path/jdk/bin
node tests/runtime-reference.test.js
```

Генератор компилирует только наш небольшой адаптер RuntimeReference.java,
а вычисления выполняют оригинальные классы из переданного JAR. SHA-256
исходного JAR записывается в эталон; смена сборки требует повторного аудита.

После исправлений прошли 19 модульных и 12 браузерных проверок, lint и
production build. Браузерные проверки включают фактическую прозрачность
canvas для форматов 2/3 и длительность при скорости 1×. Необязательная
проверка опубликованного API пропущена: этот аудит проверяет локальный код.
